# SAPUI5 Local Data Architecture & Code Quality Reference Standard
> **Document Role:** Direct Prompt, Architecture Template & Evaluation Benchmark for AI Agents auditing, scaffolding, or refactoring SAPUI5 applications powered by **Local Data (JSONModel)** rather than remote OData services.
> **Complements:** `UI5_REFERENCE_STANDARDS.md` (OData V2 benchmark).

---

## 1. Quick Identity & Stack Specification (Local Data Pattern)

| Attribute | Standard Value | Description / Rule |
| :--- | :--- | :--- |
| **Namespace / App ID** | `com.<company>.<appname>` | Defined in `manifest.json` (`sap.app.id`) and controllers |
| **UI5 Core Version** | `>= 1.141.1` (or `>= 1.120.x`) | Declared in `manifest.json` under `minUI5Version` |
| **Language** | **JavaScript (ES6+)** | Modern ES6+ (`const`, `let`, `async/await`, arrow functions, destructuring). No TypeScript |
| **Theme** | `sap_horizon` | Standard Fiori Horizon theme declared in `manifest.json` and tooling |
| **Data Architecture** | **Client-Side JSONModel** | 100% in-memory data management via `sap.ui.model.json.JSONModel` |
| **Default Model (`""`)** | Local `JSONModel` | Mapped to `model/localModel.json` or defined as empty model initialized in `Component.js` |
| **Async View Creation** | Mandatory | `sap.ui.core.IAsyncContentCreation` in `Component.js` + `"async": true` in routing |
| **Offline / Mock Ready** | Native | Runs autonomously without OData proxy or backend connectivity |

## 3. `manifest.json` Configuration for Local Models

In Local Data mode, **no OData dataSources** are required. The models are declared directly under `sap.ui5.models`:

### Pattern A: Default Model Mapped Directly to `localModel.json`
```json
{
  "sap.ui5": {
    "dependencies": {
      "minUI5Version": "1.141.1",
      "libs": {
        "sap.m": {},
        "sap.ui.core": {},
        "sap.ui.layout": {}
      }
    },
    "models": {
      "i18n": {
        "type": "sap.ui.model.resource.ResourceModel",
        "settings": {
          "bundleName": "com.mycompany.myapp.i18n.i18n",
          "supportedLocales": ["es", "en"],
          "fallbackLocale": "es"
        }
      },
      "": {
        "type": "sap.ui.model.json.JSONModel",
        "uri": "model/localModel.json"
      },
      "localModel": {
        "type": "sap.ui.model.json.JSONModel",
        "uri": "model/localModel.json"
      }
    }
  }
}
```

### Pattern B: Default Empty Model Initialized Programmatically in `Component.js`
When dynamic seeding or localStorage persistence is needed:
```json
{
  "models": {
    "": {
      "type": "sap.ui.model.json.JSONModel"
    },
    "localModel": {
      "type": "sap.ui.model.json.JSONModel",
      "uri": "model/localModel.json"
    }
  }
}
```

## 4. `webapp/model/localModel.json` Architecture

The `localModel.json` acts as the complete client-side relational store, session cache, and form state tree:

```json
{
  "Users": [
    {
      "code": "USR001",
      "userId": "jdoe@company.com",
      "firstName": "John",
      "lastName": "Doe",
      "email": "jdoe@company.com",
      "salesOffice_code": "OFC_USA",
      "userRoles": [
        { "role_code": "ADMIN" },
        { "role_code": "GVI" }
      ],
      "isActive": true
    }
  ],
  "Countries": [
    { "code": "US", "name": "United States", "descr": "North America" },
    { "code": "CL", "name": "Chile", "descr": "South America" },
    { "code": "ES", "name": "Spain", "descr": "Europe" }
  ],
  "Roles": [
    { "code": "ADMIN", "name": "Administrator" },
    { "code": "MASTER_DATA", "name": "Master Data Manager" },
    { "code": "CONTROLLER", "name": "Financial Controller" },
    { "code": "GVI", "name": "GVI Manager" }
  ],
  "create": {
    "users": {},
    "countries": {},
    "salesOffices": {}
  },
  "config": {
    "users": ["code", "userId", "firstName", "lastName", "email", "isActive", "salesOffice_code", "userRoles"],
    "countries": ["code", "name", "descr"],
    "isCreate": true
  },
  "isEdit": false
}
```

### Key Schema Nodes:
1. **Entity Arrays (Root level):** Capitalized plural names (`/Users`, `/Countries`, `/Roles`, `/SalesOffices`) acting as mock database tables bound to `<Table items="{/Users}">`.
2. **`create` node:** Sub-objects (`/create/<entity>`) bound directly to Create/Edit dialog inputs (e.g. `{localModel>/create/users/firstName}`).
3. **`config` node:** Contains active field definitions per entity for clean cloning during edits.
4. **`isEdit` flag:** Master boolean toggling dialog title (`Create` vs `Edit`) and key field editability.

## 5. Reusable Modules for Local Architecture

### 5.1. `webapp/utils/Utilities.js` (Local Data Engine)
In a local data setup, `Utilities.js` encapsulates array operations, synthetic key generation, and form validation:

```javascript
sap.ui.define([], function () {
    "use strict";

    let that;

    return {
        oModel: null,

        init: function (oModel) {
            that = this;
            that.oModel = oModel;
        },

        /**
         * Generate unique alphanumeric ID
         */
        generateId: function (sPrefix = "ID_") {
            return sPrefix + Date.now().toString(36) + Math.random().toString(36).substring(2, 6).toUpperCase();
        },

        /**
         * Local CREATE: Appends record to target array in localModel
         * @param {string} sEntityPath - e.g. "/Users"
         * @param {object} oData - Item to insert
         * @returns {Promise<object>}
         */
        createLocal: function (sEntityPath, oData) {
            return new Promise((resolve, reject) => {
                try {
                    let aItems = that.oModel.getProperty(sEntityPath) || [];
                    // Clone to avoid reference pollution
                    const oNewItem = Object.assign({}, oData);
                    aItems.push(oNewItem);
                    that.oModel.setProperty(sEntityPath, aItems);
                    that.oModel.refresh(true);
                    resolve(oNewItem);
                } catch (err) {
                    reject(err);
                }
            });
        },

        /**
         * Local READ: Reads entity collection or single item by predicate
         * @param {string} sEntityPath - e.g. "/Users"
         * @param {function} [fnFilter] - Optional filter predicate (item => boolean)
         * @returns {Promise<Array|object>}
         */
        readLocal: function (sEntityPath, fnFilter) {
            return new Promise((resolve) => {
                const aData = that.oModel.getProperty(sEntityPath) || [];
                if (typeof fnFilter === "function") {
                    resolve(aData.filter(fnFilter));
                } else {
                    resolve(aData);
                }
            });
        },

        /**
         * Local UPDATE: Updates item matching primary key in target array
         * @param {string} sEntityPath - e.g. "/Users"
         * @param {string} sKeyField - e.g. "code" or "userId"
         * @param {object} oDataToUpdate
         * @returns {Promise<object>}
         */
        updateLocal: function (sEntityPath, sKeyField, oDataToUpdate) {
            return new Promise((resolve, reject) => {
                try {
                    let aItems = that.oModel.getProperty(sEntityPath) || [];
                    const index = aItems.findIndex(item => item[sKeyField] === oDataToUpdate[sKeyField]);
                    if (index === -1) {
                        return reject(new Error(`Item with ${sKeyField}=${oDataToUpdate[sKeyField]} not found.`));
                    }
                    aItems[index] = Object.assign({}, aItems[index], oDataToUpdate);
                    that.oModel.setProperty(sEntityPath, aItems);
                    that.oModel.refresh(true);
                    resolve(aItems[index]);
                } catch (err) {
                    reject(err);
                }
            });
        },

        /**
         * Local DELETE: Removes item matching primary key from target array
         * @param {string} sEntityPath - e.g. "/Users"
         * @param {string} sKeyField - e.g. "code"
         * @param {any} keyValue - value of key to match
         * @returns {Promise<boolean>}
         */
        removeLocal: function (sEntityPath, sKeyField, keyValue) {
            return new Promise((resolve, reject) => {
                try {
                    let aItems = that.oModel.getProperty(sEntityPath) || [];
                    const aFiltered = aItems.filter(item => item[sKeyField] !== keyValue);
                    that.oModel.setProperty(sEntityPath, aFiltered);
                    that.oModel.refresh(true);
                    resolve(true);
                } catch (err) {
                    reject(err);
                }
            });
        },

        /**
         * Validate form inputs inside dialog aggregations and extract clean data
         */
        validateAndPrepareData: function (oEvent, oLocalModel, sProperty = "create/users") {
            const oParent = oEvent.getSource().getParent();
            const aContent = (oParent && typeof oParent.getAggregation === "function") 
                ? oParent.getAggregation("content") 
                : (oParent && oParent.mAggregations && oParent.mAggregations.content) || [];

            let mAggregations = null;
            if (Array.isArray(aContent)) {
                const oForm = aContent.find(c => c && typeof c.isA === "function" && c.isA("sap.ui.layout.form.Form"));
                if (oForm) {
                    mAggregations = oForm.mAggregations;
                }
            }

            const bHasEmptyFields = this.validateFields(mAggregations);
            if (bHasEmptyFields) {
                return false;
            }

            return Object.assign({}, oLocalModel.getProperty(`/${sProperty}`));
        },

        /**
         * Evaluates FormElements and sets ValueState (Error vs None)
         */
        validateFields: function (mAggregations) {
            if (!mAggregations || !mAggregations.formContainers) {
                return false;
            }
            const aFormContainers = mAggregations.formContainers;
            const aEmptyFields = [];

            aFormContainers.forEach(oContainer => {
                oContainer.getFormElements().forEach(oElement => {
                    if (oElement.getVisible()) {
                        const oField = oElement.getFields()[0];
                        if (!oField) {
                            return;
                        }

                        if (oField instanceof sap.m.ComboBox || oField instanceof sap.m.Select) {
                            const bEmpty = !oField.getSelectedKey();
                            oField.setValueState(bEmpty ? "Error" : "None");
                            aEmptyFields.push(bEmpty ? "Error" : "None");
                        } else if (oField instanceof sap.m.MultiComboBox) {
                            const bEmpty = oField.getSelectedKeys().length === 0;
                            oField.setValueState(bEmpty ? "Error" : "None");
                            aEmptyFields.push(bEmpty ? "Error" : "None");
                        } else if (oField instanceof sap.m.Input) {
                            const bEmpty = !oField.getValue() || oField.getValue().trim() === "";
                            oField.setValueState(bEmpty ? "Error" : "None");
                            aEmptyFields.push(bEmpty ? "Error" : "None");
                        }
                    }
                });
            });

            return aEmptyFields.some(state => state === "Error");
        },

        /**
         * Clears all ValueStates to None
         */
        cleanValueState: function (mAggregations) {
            if (!mAggregations || !mAggregations.formContainers) {
                return;
            }
            mAggregations.formContainers.forEach(oContainer => {
                oContainer.getFormElements().forEach(oElement => {
                    oElement.getFields().forEach(oField => {
                        if (oField && typeof oField.setValueState === "function") {
                            oField.setValueState("None");
                        }
                    });
                });
            });
        }
    };
});
```

### 5.2. `webapp/controller/BaseController.js` (Local Model Foundation)

```javascript
sap.ui.define([
    "sap/ui/core/mvc/Controller",
    "sap/m/MessageBox",
    "sap/m/MessageToast",
    "sap/ui/core/Fragment",
    "../utils/Utilities"
], function (Controller, MessageBox, MessageToast, Fragment, Utilities) {
    "use strict";

    return Controller.extend("com.mycompany.myapp.controller.BaseController", {

        getRouter: function () {
            return sap.ui.core.UIComponent.getRouterFor(this);
        },

        getModel: function (sName) {
            return this.getView().getModel(sName) || this.getOwnerComponent().getModel(sName);
        },

        setModel: function (oModel, sName) {
            return this.getView().setModel(oModel, sName);
        },

        getResourceBundle: function () {
            return this.getOwnerComponent().getModel("i18n").getResourceBundle();
        },

        getLocalModel: function () {
            return this.getModel("localModel") || this.getModel();
        },

        getLocalProperty: function (sPath) {
            return this.getLocalModel().getProperty(sPath);
        },

        setLocalProperty: function (sPath, oValue) {
            return this.getLocalModel().setProperty(sPath, oValue);
        },

        showMessage: function (sType, sMessage, sDetail) {
            return new Promise((resolve) => {
                switch (sType) {
                    case "Error":
                        MessageBox.error(sMessage, { details: sDetail });
                        break;
                    case "Success":
                        MessageBox.success(sMessage);
                        break;
                    case "Warning":
                        MessageBox.warning(sMessage, { details: sDetail });
                        break;
                    default:
                        MessageBox.information(sMessage);
                }
                resolve();
            });
        },

        onOpenDlg: function (sFragmentName, fnAdicional) {
            const that = this;
            if (!that[sFragmentName]) {
                that[sFragmentName] = Fragment.load({
                    id: that.getView().getId(),
                    name: `com.mycompany.myapp.view.fragment.create.${sFragmentName}`,
                    controller: that
                }).then(function (oFragment) {
                    that.getView().addDependent(oFragment);
                    return oFragment;
                });
            }

            that[sFragmentName].then(function (oDialog) {
                const mAggregations = oDialog.mAggregations.content?.[0]?.mAggregations;
                if (mAggregations) {
                    Utilities.cleanValueState(mAggregations);
                }
                if (typeof fnAdicional === "function") {
                    fnAdicional();
                }
                oDialog.open();
            });
        },

        onCloseDlg: function (sFragmentName) {
            if (this[sFragmentName]) {
                this[sFragmentName].then(oDialog => oDialog.close());
            }
        }
    });
});
```

### 5.3. `webapp/controller/Main.controller.js` (Local CRUD Implementation)

```javascript
sap.ui.define([
    "./BaseController",
    "../utils/Utilities",
    "../model/formatter",
    "sap/m/MessageBox",
    "sap/m/MessageToast",
    "sap/ui/model/Filter",
    "sap/ui/model/FilterOperator"
], function (BaseController, Utilities, formatter, MessageBox, MessageToast, Filter, FilterOperator) {
    "use strict";

    return BaseController.extend("com.mycompany.myapp.controller.Main", {
        formatter: formatter,

        onInit: function () {
            this._oLocalModel = this.getLocalModel();
            this._oResourceBundle = this.getResourceBundle();

            // Initialize Utilities with the local model
            Utilities.init(this._oLocalModel);
        },

        /* Open Create Dialog */
        onOpenDialog: function (sFragmentName, sEntity) {
            this.setLocalProperty("/isEdit", false);
            this.setLocalProperty("/config/isCreate", true);
            this.setLocalProperty(`/create/${sEntity}`, {});

            this.onOpenDlg(sFragmentName);
        },

        /* Save Record (Create or Edit in Local Model) */
        onSave: async function (oEvent, sEntityCollection, sProperty, sFragmentName, sKeyField = "code") {
            const bCreate = this.getLocalProperty("/config/isCreate");
            const oData = Utilities.validateAndPrepareData(oEvent, this._oLocalModel, `create/${sProperty}`);

            if (!oData) {
                return; // Form invalid
            }

            try {
                if (bCreate) {
                    await Utilities.createLocal(`/${sEntityCollection}`, oData);
                    MessageBox.success(this._oResourceBundle.getText(`msg.success.${sProperty}.create`, [oData[sKeyField]]));
                } else {
                    await Utilities.updateLocal(`/${sEntityCollection}`, sKeyField, oData);
                    MessageBox.success(this._oResourceBundle.getText(`msg.success.${sProperty}.edit`, [oData[sKeyField]]));
                }
                this.onCloseDlg(sFragmentName);
            } catch (err) {
                MessageBox.error(err.message || "Error al procesar la operación local.");
            }
        },

        /* Open Edit Dialog */
        onHandleEdit: function (oEvent, sFragmentName, sProperty, sKeyField = "code") {
            const oContext = oEvent.getSource().getBindingContext();
            const oRowData = oContext.getObject();

            MessageBox.confirm(
                this._oResourceBundle.getText(`msg.confirm.${sProperty}.edit`, [oRowData[sKeyField]]),
                {
                    title: this._oResourceBundle.getText("confirmTitle"),
                    onClose: (sAction) => {
                        if (sAction === MessageBox.Action.OK) {
                            this.setLocalProperty("/isEdit", true);
                            this.setLocalProperty("/config/isCreate", false);

                            // Clone data into /create/<entity>
                            const aFields = this.getLocalProperty(`/config/${sProperty}`) || Object.keys(oRowData);
                            const oBuffer = {};
                            aFields.forEach(f => {
                                oBuffer[f] = oRowData[f];
                            });
                            this.setLocalProperty(`/create/${sProperty}`, oBuffer);

                            this.onOpenDlg(sFragmentName);
                        }
                    }
                }
            );
        },

        /* Confirm & Delete Record */
        onConfirmDelete: function (oEvent, sEntityCollection, sKeyField = "code") {
            const oRowData = oEvent.getSource().getBindingContext().getObject();
            const sId = oRowData[sKeyField];

            MessageBox.confirm(
                this._oResourceBundle.getText("confirmDelete", [sId]),
                {
                    title: this._oResourceBundle.getText("confirmTitle"),
                    onClose: async (sAction) => {
                        if (sAction === MessageBox.Action.OK) {
                            try {
                                await Utilities.removeLocal(`/${sEntityCollection}`, sKeyField, sId);
                                MessageToast.show(this._oResourceBundle.getText("deleteSuccess", [sId]));
                            } catch (err) {
                                MessageBox.error(err.message || "Error al eliminar registro local.");
                            }
                        }
                    }
                }
            );
        },

        /* Local Table Search */
        onSearch: function (oEvent, sTableId, aSearchFields = ["code", "name"]) {
            const sQuery = (oEvent.getParameter("query") || oEvent.getParameter("newValue") || "").trim();
            const oTable = this.byId(sTableId);
            const oBinding = oTable.getBinding("items");

            if (!sQuery) {
                oBinding.filter([]);
                return;
            }

            const aFilters = aSearchFields.map(field => 
                new Filter(field, FilterOperator.Contains, sQuery)
            );
            oBinding.filter(new Filter({ filters: aFilters, and: false }));
        }
    });
});
```

## 7. AI Agent Audit Checklist for Local Data Projects

When an AI agent audits a UI5 repository intended to use the **Local Data Pattern**, it must verify every point:

### 1. Model Configuration (`manifest.json`)
- [ ] No remote OData dataSources defined or left dangling without an active proxy.
- [ ] Model `""` (default) and/or `localModel` are declared as `"type": "sap.ui.model.json.JSONModel"`.
- [ ] `uri` correctly points to `"model/localModel.json"`.

### 2. State & Data Seed (`model/localModel.json`)
- [ ] `localModel.json` exists in `webapp/model/`.
- [ ] Collections are initialized as root arrays (e.g. `"Users": []`).
- [ ] Form buffers are pre-allocated under `"create": { ... }`.
- [ ] Field lists are mapped under `"config": { ... }` for controlled entity editing.
- [ ] Boolean flag `"isEdit"` exists at root.

### 3. Architecture & Utilities (`Utilities.js` & `BaseController.js`)
- [ ] `Utilities.js` implements synchronous or Promise-based local CRUD (`createLocal`, `readLocal`, `updateLocal`, `removeLocal`).
- [ ] No `oModel.read(...)` or `oModel.create(...)` OData methods called against local models.
- [ ] Form validation inspects aggregations and properly sets `ValueState` (`Error` / `None`).
- [ ] `cleanValueState` resets fields upon opening dialogs.
- [ ] BaseController provides `getLocalModel()`, `getLocalProperty()`, `setLocalProperty()`, `onOpenDlg()`, `onCloseDlg()`.

### 4. Code Standards & Naming
- [ ] Strict mode `"use strict";` in every AMD module.
- [ ] Hungarian notation used throughout: `oModel`, `aItems`, `sEntity`, `bCreate`.
- [ ] UI event handlers prefixed with `on` (`onSave`, `onConfirmDelete`, `onSearch`).
- [ ] Instance state stored on `this` (e.g. `this._oLocalModel`), avoiding shared closure variable leaks.
- [ ] Hardcoded user-visible text is prohibited; all strings resolved via `i18n`.
